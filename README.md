# 团支书工作台

高校团支书日常团务管理的本地工具。纯 HTML/CSS/JS，浏览器直接打开即用，数据存本地 localStorage，无需后端、无需数据库。

## 功能

- **团员管理**：花名册、Excel 批量导入/导出、JSON 备份与恢复
- **三会两制一课**：支部大会 / 支部委员会 / 团小组会 / 团课记录
- **推优入党**：候选人管理、入党申请人台账
- **团费 / 活动 / 荣誉 / 志愿时长 / 考勤**：多维度台账
- **数据可视化**：知识图谱、进度环、总览仪表盘

## 快速开始

方式一：直接用浏览器打开 `index.html`。

方式二：桌面壳启动（可选，提供 pywebview 桥接能力）：

```bash
python scripts/启动工作台.py
```

## 数据说明

> 仓库内所有数据均为**示例数据**，已做脱敏处理，不含任何真实个人信息。

首次使用时，请通过界面里的「导入」功能导入自己的花名册（支持 Excel / JSON），数据仅保存在你本地的 localStorage 中。

## 技术栈

- 原生 HTML / CSS / JS，零框架
- localStorage 本地存储
- GSAP 动效（本地 lib）
